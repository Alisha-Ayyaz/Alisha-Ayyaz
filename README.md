## 🚀 Featured Projects

### 1. End-to-End Azure Databricks Data Pipeline
**Tech:** Azure Data Factory, ADLS Gen2, Azure Databricks, PySpark, Delta Lake, Snowflake, dbt, Unity Catalog

A cloud lakehouse pipeline designed around **Medallion Architecture** to turn raw data into analytics-ready datasets.

- Ingested data from ADLS Gen2 using Azure Data Factory into the Bronze layer.
- Transformed and cleaned datasets with PySpark and Delta Lake in Azure Databricks.
- Applied surrogate keys and dimensional modeling techniques in the Gold layer.
- Loaded curated data into Snowflake and built modular dbt models and data marts.
- Added dbt quality tests, documentation, and lineage; orchestrated processing with Databricks Jobs/Workflows.

### 2. Open Source Data Gathering (OSDG) — Final Year Project
**Tech:** Python, REST APIs, Web Scraping, React, React Flow, Vite, Tailwind CSS, Git

A data gathering and visualization application that collects and connects information from multiple sources.

- Developed a Python data pipeline to gather information from real-world APIs and web sources.
- Cleaned, validated, and deduplicated collected data before serving it through REST APIs.
- Used asynchronous Python for concurrent scraping tasks and logging for error tracking.
- Built an interactive graph interface with React Flow to explore connected data.

### 3. Hospital Management System Dashboard
**Tech:** Power BI, DAX, Power Query, ETL

An interactive analytics dashboard for hospital operations and performance monitoring.

- Extracted and transformed data from multiple sources with Power Query.
- Created DAX measures for bed occupancy, patient flow, and revenue trends.
- Added slicers, drill-through pages, and dynamic filters for exploration.

### 4. Business Intelligence Insights Dashboard
**Tech:** Tableau, SQL, Data Blending, LOD Expressions

A business reporting solution that combines multiple data sources for decision-making.

- Integrated data using SQL joins and Tableau data blending.
- Developed calculated fields, parameters, and LOD expressions.
- Created interactive dashboards for granular analysis and executive reporting.

### 5. Data Analysis of Automobile Industry
**Tech:** Python, Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn

A Data Science project exploring automobile data and building a predictive classification model.

- Performed EDA, correlation analysis, and outlier detection.
- Handled missing values, encoded categories, and scaled features.
- Built a Decision Tree Classifier and evaluated it with cross-validation and classification metrics.

### 6. Streamlit Portfolio Showcase
**Tech:** Python, Streamlit, GitHub, Streamlit Cloud

A deployed interactive web application for browser-based data visualization.

- Built a Streamlit application for interactive visualizations.
- Managed code with Git/GitHub and deployed through Streamlit Cloud.
